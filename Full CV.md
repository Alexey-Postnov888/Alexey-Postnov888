### Backend

#### Система информирования студентов

> Участвую в командной разработке по Scrum (Agile) удобной и централизованной системы для взаимодействия между учебной частью и студентами. Мой вклад в проект:

- Спроектировал архитектуру всего проекта: какие микросервисы, как они взаимодействуют между собой, как клиенты взаимодействуют с бэкендом, общение через единую точку входа - API Gateway, RabbitMQ, Docker оркестрация всей системы, БД.
- Разработал микросервис авторизации на Ktor с выдачей JWT Access/Refresh токенов и ролевой моделью доступа (студент, студсовет, методист, деканат и тп), интеграция с Keycloak.
- Разработал микросервис маршрутизации (API Gateway) как единую точку входа для микросервисов и клиентов, предоставляющий необходимые эндпоинты.
- Разработал микросервисы для информирования и системы уведомлений, работы с баллами активистов.
- Внедрил RabbitMQ для асинхронного взаимодействия сервисов.
- Настроил взаимодействие между всеми микросервисами и клиентами (Telegram бот и веб).

Планируемое развитие: продолжение командной разработки, двигаться дальше по плану: ИИ-ассистент (RAG-система), масштабирование системы, добавление нового функционала, улучшение существующего, создание Android-клиента и тп.

Примечание: репозиторий приватный, поскольку система используется на факультете.

Стек: Ktor, PostgreSQL, Docker Compose, Keycloak, RabbitMQ

### DevOps

- Развернул физический сервер с Proxmox VE для виртуализации.
- Настроил виртуальные машины на Ubuntu Server, где изолированно друг от друга запущены сервисы через Docker и Docker Compose.
- Настроил Nginx в роли обратного прокси для маршрутизации запросов с доменов к соответствующим контейнерам с сервисами (2 ВМ, 20+ контейнеров) Обеспечил безопасное соединение, настроив SSL-сертификаты Let’s Encrypt с помощью Certbot для всех публичных сервисов, сертификаты автоматически продлеваются.
- Развернул Grafana и Prometheus для мониторинга состояния сервера и виртуальных машин.

#### Результат

Приобрёл практические навыки развёртывания и поддержки серверной инфраструктуры.
