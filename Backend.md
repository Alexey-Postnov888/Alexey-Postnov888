### DevOps

- Развернул физический сервер с Proxmox VE для виртуализации.
- Настроил виртуальные машины на Ubuntu Server, где изолированно друг от друга запущены сервисы через Docker и Docker Compose.
- Настроил Nginx в роли обратного прокси для маршрутизации запросов с доменов к соответствующим контейнерам с сервисами (2 ВМ, 20+ контейнеров). Обеспечил безопасное соединение, настроив SSL-сертификаты Let’s Encrypt с помощью Certbot для всех публичных сервисов, сертификаты автоматически продлеваются.
- Развернул Grafana и Prometheus для мониторинга состояния сервера и виртуальных машин.
